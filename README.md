# My-first-project
🏥 SmartCare Hospital Analytics System

Project Title

SmartCare Hospital Analytics System

---

Problem Statement

Hospitals often struggle to monitor patient records, bed availability, emergency cases, disease information, and hospital performance from a single platform. Manual monitoring is time-consuming and can delay decision-making. SmartCare provides an interactive analytics dashboard that presents hospital information in a clear and organized manner for better management.

---

Project Overview

SmartCare Hospital Analytics System is a web-based dashboard developed using HTML, CSS, and JavaScript. It visualizes hospital statistics such as patient visits, bed occupancy, emergency admissions, disease information, infrastructure details, and healthcare analytics. The project simulates a modern Hospital Management Dashboard with an attractive user interface and interactive features.

Installation Steps

1. Clone the repository:

git clone https://github.com/payalkale96k-eng/My-first-project-.git

2. Open the project folder:

cd My-first-project-

3. Open the project in Visual Studio Code.

4. Install the Live Server extension (if not already installed).

5. Right-click on index.html and select "Open with Live Server".

6. The SmartCare Hospital Analytics System will open in your web browser.
